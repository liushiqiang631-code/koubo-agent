# 口播智能体

AI 数字人口播视频创作平台（本地部署版）：**AI 文案生成 → 数字人 + 神经语音合成 → 自动渲染带字幕的口播视频 → 发布助手**，一条龙全部在本机完成。

![首页](#) （运行后访问 http://localhost:7788 查看界面）

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 首页创作台 | 文案编辑器（AI 生成 / 导入 / 模板 / AI 优化 / 一键润色）、数字人选择、声音设置（音色/语速/情绪/停顿 + 试听）、视频预览、快速操作、发布渠道 |
| 创作中心 | 作品管理：草稿 / 排队 / 渲染中 / 已完成 / 失败重试 / 下载 / 删除 |
| 数字人 | 8 位内置矢量数字人形象（分类筛选），支持上传真人肖像照作为出镜形象 |
| 声音 | 8 种微软神经网络音色，支持试听；离线环境自动回退 Windows 系统语音 |
| 文案 | 文案库（AI 生成自动入库）、模板库（干货 / 种草 / 故事 / 资讯） |
| 素材库 | 图片 / 音频素材上传管理，肖像照可直接用于视频渲染 |
| 发布 | 发布助手：自动生成标题文案与话题标签、渠道发布状态管理、下载视频与封面 |
| 数据 | 全部真实本地数据：作品数、总时长、渲染成功率、近 7 天趋势、TOP 作品 |
| 设置 | 可配置任意 OpenAI 兼容大模型（DeepSeek / 通义 / GLM / Kimi…）、画幅、帧率、画质、水印 |

## 🚀 快速开始

**Windows 一键启动：双击项目根目录的 `启动.bat`** —— 自动检查 Node 环境（首次自动装依赖、自动构建前端）→ 启动服务 → 接口就绪后自动打开浏览器 http://localhost:7788。关闭黑色窗口即停止服务；若服务已在运行则直接打开页面，不会重复启动。

命令行方式：

```bash
npm install          # 若网络受限导致安装失败，可运行: node rescue-deps.js --force
npm run build        # 构建前端
npm start            # 启动服务 → http://localhost:7788
```

开发模式：`npm run dev:front`（Vite 热更新，代理 API 到 7788）+ `npm run server`。

局域网使用：其他设备访问 `http://<本机IP>:7788`。

环境要求：Node ≥ 18、Python 3（edge-tts 库，`pip install edge-tts`）、ffmpeg 在 PATH 中、Windows（SAPI 兜底语音）。

## 🎬 使用流程

1. 首页 →「AI 生成文案」输入主题（如"如何做好时间管理"），选择风格与时长，一键成稿；
2. 选择数字人与声音，调节语速 / 情绪 / 停顿，点「试听」确认；
3. 点「生成口播」→ 自动完成语音合成、字幕对齐、视频渲染（右下角实时进度）；
4. 预览满意后到「发布」页复制文案话题、下载视频与封面上传平台。

## 🧱 技术实现

- **前端** React 18 + Vite + React Router，纯手写样式还原设计稿
- **后端** Node.js + Express + JSON 文件数据库（`server/data/`），任务队列串行渲染
- **文案引擎** 双引擎：配置了 LLM 走 OpenAI 兼容接口；未配置用内置本地结构化生成（钩子→共鸣→要点→总结→CTA，按目标字数自动裁剪），离线可用
- **语音合成** Python edge-tts（微软神经语音，免费）逐句合成 + PCM 静音拼接实现三档句间停顿，输出词级时间戳；失败自动回退 Windows SAPI
- **视频渲染** ffmpeg：Pillow 绘制数字人场景底图 → zoompan 缓慢推镜 → 字幕按词级时间戳预渲染 PNG 后 overlay（规避部分 Windows ffmpeg 构建 drawtext/libass 的崩溃问题）→ H.264 + AAC，支持 9:16 / 16:9

## 📁 目录

```
├─ server/
│  ├─ index.js            # Express 入口与全部 REST API
│  ├─ worker.js           # 渲染任务队列
│  ├─ db.js / config.js   # JSON 数据库 / 配置
│  └─ services/
│     ├─ tts.js           # 语音合成（Edge→SAPI 引擎链）
│     ├─ tts_edge.py      # edge-tts 单句合成桥接（mp3 + 词级时间戳）
│     ├─ llm.js           # 文案生成 / 润色（LLM + 本地双引擎）、模板库
│     ├─ render.js        # ffmpeg 渲染管线
│     ├─ avatars.js       # 数字人目录与 SVG 形象
│     └─ scene.py         # Pillow 场景底图 / 字幕 / 水印渲染
├─ frontend/src/          # React 页面（首页/创作中心/数字人/声音/文案/素材库/发布/数据/设置/帮助）
├─ 启动.bat               # Windows 双击启动器：环境自检 + 启服务 + 自动开浏览器
├─ rescue-deps.js         # npm 安装失败时的依赖修复工具
└─ server/data/           # 运行时数据（数据库、媒体、上传素材），已 gitignore
```

## ⚠️ 能力边界（诚实说明）

- **语音合成 / 视频渲染 / 文案生成 / 数据统计** 完全本地可用，开箱即用；
- 数字人为「形象 + 语音 + 词级对齐字幕」的成片模式（主流口播账号的普遍形态），**不含唇形驱动**——那需要 GPU 级大模型推理，可后续接入；
- 抖音 / 视频号 / 小红书等的**全自动发布**需各企业开放平台资质审核，本产品提供发布助手模式（文案话题生成、状态管理、素材快速下载）；
- 平台播放量 / 转化率等数据在未接入平台 API 前不展示伪造数值，数据页全部为本地真实记录。
